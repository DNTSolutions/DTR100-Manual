# Installation

Follow these steps to install the grinder safely and correctly.

## Unpacking

1. Remove grinder from packaging.
2. Check for damage and verify contents:
   - Grinder unit
   - Electrode holder
   - Power cable
   - 5 mm Allen key
   - Spare fuse (T2A)

## Mounting

- Secure to workbench using 4x M6 bolts (not supplied).
- Ensure stable, level surface away from water/flammable materials.
- Leave 10 cm clearance on all sides for ventilation.

## Electrical Connection

1. Verify supply: 220-240V AC, 50/60 Hz, grounded outlet.
2. Insert power cable into rear socket and plug in.
3. Install fuse if removed (T2A slow-blow).

## Initial Test

1. Power on—green LED should illuminate steadily.
2. Listen for smooth motor spin-up (no grinding noise).
3. Verify electrode holder clamps securely.

Proceed to **Basic Operation** only after successful test.[cite:40]
