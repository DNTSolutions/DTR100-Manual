# Overview

Welcome to the Tungsten Grinder.  
This guide gives a high-level overview so you can **set up** the machine quickly and use it safely.

## What this machine does

- Produces consistent, repeatable tungsten electrode tips for TIG welding.
- Improves arc stability and reduces tungsten contamination.
- Reduces setup time compared to manual grinding.

## Main components

- Power switch and status indicator on the front panel.
- Electrode holder with angle adjustment.
- Enclosed grinding chamber and dust outlet.
- Power input and fuse on the rear panel.

Refer to the diagram in the Installation section for connector and control locations.

## Who should read this

- Welders and technicians using the grinder in a workshop or production cell.
- Engineers responsible for welding procedure qualification or fixture setup.
- Maintenance staff servicing the grinder.

If this is your first time using the machine, read this Overview, the Safety Warning, and the Installation sections before operation.
