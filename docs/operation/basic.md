# Basic Operation

Learn how to power up, load an electrode, and perform a grind cycle.

## Powering Up

1. Ensure all guards are in place.
2. Switch power to ON—wait for green LED.
3. Motor will run at preset speed.

## Loading Electrode

1. Insert tungsten electrode into holder (max 3.2 mm dia).
2. Tighten collet with 5 mm Allen key (torque 1 Nm).
3. Adjust angle to 30° using side knob.

## Grinding

1. Insert holder fully into machine.
2. Close safety door.
3. Press START button—cycle runs 5 seconds.
4. Remove holder after beep.

Inspect tip: flat face, sharp edges, no chatter marks.[cite:40]
