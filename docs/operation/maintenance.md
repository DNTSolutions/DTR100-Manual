# Maintenance

Regular maintenance extends machine life and ensures consistent performance.

## Daily

- Empty dust tray.
- Wipe exterior with dry cloth.
- Check holder for wear.

## Weekly

- Inspect grinding wheel for damage/glazing.
- Clean air vents with compressed air.

## Every 100 Hours

1. Power off and unplug.
2. Remove wheel cover (4x M4 screws).
3. Replace wheel if worn >2 mm.
4. Re-torque screws to 2 Nm.

## Spare Parts

- Grinding wheel (60 grit diamond)
- Fuse (T2A)
- Collet set (1.0-3.2 mm)
