# Electrode Grinding

Detailed procedure for optimal tungsten preparation.

## Grinding Angles

| Angle | Application          |
|-------|----------------------|
| 20°   | Precision welding   |
| 30°   | General purpose     |
| 45°   | Heavy current       |

## Step-by-Step

1. Select angle and set knob.
2. Clean electrode end with alcohol.
3. Grind per Basic Operation.
4. Measure diameter—should match input ±0.1 mm.

## Tips for Best Results

- Use pure tungsten for longest wheel life.
- Grind only the end 6-10 mm.
- Rotate holder 90° halfway for even wear.

Discard electrode if deformed or contaminated.[cite:40]
