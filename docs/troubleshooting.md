# Troubleshooting

Common issues and solutions.

## No Power

| Symptom              | Cause                  | Solution                  |
|----------------------|------------------------|---------------------------|
| No LED, no motor     | Blown fuse             | Replace T2A fuse         |
| LED flickers         | Loose cable            | Check connections        |
| Motor hums but slow  | Low voltage            | Verify 220V supply       |

## Grinding Issues

| Symptom              | Cause                  | Solution                  |
|----------------------|------------------------|---------------------------|
| Rough tip            | Dull wheel             | Replace grinding wheel   |
| Vibration            | Unbalanced electrode   | Check centering          |
| Door won't close     | Debris                 | Clean chamber            |

## Error Prevention

- Always unplug before inspection.
- Log maintenance hours.
- Calibrate angle gauge monthly.

If issue persists, record symptoms and contact support.[cite:40]
